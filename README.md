# SIGEV - Sistema de Información para la Gestión de Ventas

Proyecto SENA · Tecnólogo en Análisis y Desarrollo de Software · Ficha 3186610
Aprendiz: Faber Stiven Londoño Gil

## Módulos
- **Productos:** registro y consulta de productos con control de stock.
- **Clientes:** registro y consulta de clientes con validaciones.
- **Ventas:** registro de ventas que descuenta el stock automáticamente.

## Tecnologías
Java · Servlets · JSP · JDBC · MySQL 8 · Apache Tomcat 10 · NetBeans

## Ejecución
1. Crear la base de datos `sigev_db` en MySQL.
2. Abrir el proyecto en NetBeans y configurar Tomcat 10.
3. Clean and Build → Run.
4. Abrir http://localhost:8080/SIGEV_Web/
